C1 · Le RL en bref

  • Apprendre un comportement par interaction : agent → action ; environnement → observation + récompense scalaire.
  • ≠ supervisé : pas d'étiquette, les actions changent les données futures.
  • 3 difficultés : données non IID · exploration / exploitation · récompense différée (attribution du crédit).
  • Agent = le décideur seul. Environnement = tout le reste (corps du robot inclus). Observation ≠ état (partielle, bruitée).
  • Récompense = définit le succès, pas le comportement. On maximise la récompense cumulée.
  • Bitter Lesson : les méthodes générales + calcul battent les connaissances codées à la main.

C1 · Rendement, valeur, politique

\[ G_t=\sum_{k\ge0}\gamma^kR_{t+k+1} \qquad V(s)=\mathbb E[G_t\mid S_t=s] \]

\(\sum_k\gamma^k=\frac1{1-\gamma}\) (γ = 0.9 → 10 ; γ = 0.95 → 20). γ = 0 : myope. γ = 1 sans fin → infini.

Ex. 2, −1, 5, γ = 0.9 : 2 − 0.9 + 4.05 = 5.15.

\(\pi(a|s)=P(A_t=a|S_t=s)\) ; fixer π → MRP :

\[ P^\pi(s'|s)=\sum_a\pi(a|s)P(s'|s,a) \] \[ R^\pi(s,s')=\sum_a\pi(a|s)R(s,a,s') \]

⚠ Une action fixe la distribution de l'état suivant, pas l'état. Même récompense immédiate ≠ même valeur.

C3 · Méthode de l'entropie croisée

  1. Jouer N épisodes avec le réseau (action échantillonnée selon softmax, pas argmax).
  2. Seuil = centile ρ des retours : np.percentile(rewards, 70).
  3. Garder les élites (retour ≥ seuil).
  4. Entraîner sur les paires (obs, action) élites avec l'entropie croisée (classification, action = étiquette).

CartPole : 128 neurones, 16 épisodes, centile 70, Adam lr 0.01 → moyenne 475 en ≈ 50 itérations.

FrozenLake échoue : récompense éparse et binaire → seuil 0. Correctifs : gros lots · score actualisé \(r\cdot\gamma^T\) · garder les élites · lr ÷ 10 · plus d'entraînement → ≈ 55 %.

⚠ Seuil 0 avec ≥ garderait les échecs → > strict. Centile haut = moins de données mais meilleures.

Justification

\[ \mathbb E_p[H]=\mathbb E_q\!\left[\tfrac{p}{q}H\right] \] \[ D_{KL}(p\|q)=\mathbb E_p[\log p]-\mathbb E_p[\log q] \]

Minimiser la KL vers les élites = minimiser l'entropie croisée → indicateur \(\mathbb 1[R\ge\psi]\) devant \(\log\pi\) :

\[ -\log\pi_\theta(x)=-\sum_t\log\pi_\theta(a_t|s_t)+c \]

C4 · Valeurs et Bellman

\(V^\pi(s)\) : rendement espéré en suivant π depuis s. \(Q^\pi(s,a)\) : faire a puis suivre π.

\[ V^\pi=\sum_a\pi(a|s)\,Q^\pi(s,a) \] \[ Q^\pi(s,a)=\sum_{s'}p(s'|s,a)[r+\gamma V^\pi(s')] \] \[ V^*(s)=\max_a\sum_{s'}p(s'|s,a)[r+\gamma V^*(s')] \] \[ Q^*(s,a)=\sum_{s'}p(s'|s,a)[r+\gamma\max_{a'}Q^*(s',a')] \]
  • Gourmand sur r immédiat = piège (+2 puis −20) : comparer \(r+\gamma V(s')\).
  • Politique fixée → système linéaire ; avec max → non linéaire.
  • Avec Q*, politique optimale = argmax, sans modèle.
  • Cycle s₁⇄s₂ (γ = 0.9) : \(V(s_1)=\frac{1+2\gamma}{1-\gamma^2}\approx14.74\).
  • Amélioration : si π′ est au moins aussi bonne en une étape partout, π′ ≥ π.

C4 · Itération de valeurs / Q-itération

  • Partir de 0, appliquer Bellman en boucle → V* si γ < 1.
  • Modèle estimé par comptage : \(\hat p(s'|s,a)=\frac{N(s,a,s')}{\sum_xN(s,a,x)}\)
  • FrozenLake : 100 pas aléatoires → mise à jour → 20 épisodes de test (sur un test_env séparé).
  • Tables : récompenses par (s,a,s′), transitions par (s,a), valeurs par s.
  • Q-itération : stocke Q(s,a) (4× plus), action = argmax directe.
  • ≈ 65 % vs 55 % (CEM) sur 8×8. Limites : états discrets et peu nombreux, modèle requis, récompenses éparses.

\[ y=r+\gamma\max_{a'}Q(s',a')\quad(y=r\text{ si terminal}) \] \[ Q\leftarrow(1-\alpha)Q+\alpha y=Q+\alpha(y-Q) \]

  • TD(0) · SARSA : \(Q(s_{t+1},a_{t+1})\), on-policy (action jouée) · Q-learning : max, off-policy.
  • FrozenLake ≈ 3000 itérations.

C6 · Extensions (Rainbow)

N pas

\[ y_t=\sum_{k=0}^{n-1}\gamma^kr_{t+k}+\gamma^n\max_{a'}\hat Q(s_{t+n},a') \]

Propagation plus rapide ; n = 2–3 aide ; grand n = variance (actions intermédiaires non optimales).

Double DQN

\[ y=r+\gamma\hat Q\big(s',\arg\max_aQ(s',a)\big) \]

Q choisit, Q̂ évalue → moins de surestimation. Change la cible, pas l'architecture.

Réseaux bruités

\(w=\mu+\sigma\epsilon,\ \epsilon\sim\mathcal N(0,1)\) ; μ, σ appris (pas ε). Exploration dépendante de l'état, plus de calendrier ε.

Rejeu prioritaire (PER)

\[ p_i=|\delta_i|+\varepsilon_p,\quad P(i)=\frac{p_i^\alpha}{\sum_kp_k^\alpha},\quad w_i=(N\,P(i))^{-\beta} \]

β → 1. α = 0 → tirage uniforme. Gain surtout en début d'entraînement.

Dueling

\[ Q=V+A-\tfrac1{|A|}\textstyle\sum_{a'}A(s,a') \]

Deux têtes sur un tronc CNN ; centrer A rend V, A identifiables.
